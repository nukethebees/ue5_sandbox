# Celestial Backdrop

`ACelestialBackdropActor` renders configurable planets, moons, and other large background bodies.
It is scenery only: it has no collision, physics, navigation, shadow, or gameplay role.

Place the actor, set its radius and sun direction, select a render mode, and assign or override an
appearance profile. See [ARCHITECTURE.md](ARCHITECTURE.md) for renderer modes, profile ownership,
close-approach behaviour, and limitations.
